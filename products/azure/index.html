Microsoft chips speed chip design up to 4x

✨What's new

Microsoft ran its own chip-design workloads on Azure Cobalt 200 virtual machines and saw 1.3x to 4.15x the performance of Cobalt 100, with tools from Cadence, Synopsys and Siemens unchanged.

Compute-heavy engineering teams can get more work done per core on Azure's own chips.
