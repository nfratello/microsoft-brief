The Microsoft Brief
What's new from Microsoft, and why it matters to manufacturers. 5-minute read.

Good morning,

Dynamics 365 made big moves for manufacturers this week, and agents keep getting more useful on the plant floor and in the back office. Here's what matters.

3 must-reads
1. Turn every machine into recurring revenue—rental now runs inside your ERP.
2. Supplier slipped a date? An ERP agent spots at-risk orders first.
3. Agents that remember, start themselves, and keep plant work moving overnight.
Dynamics 365 (ERP)
Your machines can become a subscription business

What's new: Rental Management enters public preview in Supply Chain Management, with linked rental features in Field Service and Commerce for one connected asset lifecycle.

Why it matters: Equipment makers can add rental and service revenue on existing ERP, tracking each unit's utilization, maintenance and profitability without bolt-on systems.

Read the announcement →  Microsoft Dynamics 365 Blog
Dynamics 365 (ERP)
An ERP agent that spots at-risk orders before you do

What's new: Gartner rated Microsoft a Leader in product-centric cloud ERP; the post highlights the Procurement Agent and Copilot working on supply chain data.

Why it matters: Planners and buyers get agents that flag at-risk orders when suppliers slip dates, easing tariff, lead-time and labor-shortage pressure.

Read the report summary →  Microsoft Dynamics 365 Blog
Copilot Studio
Agents that remember and start work on their own

What's new: October roundup: agent accounts, business process memory and event or schedule triggers (Frontier preview), plus a Copilot Studio MCP server and in-chat connector setup.

Why it matters: Agents can own recurring tasks like order exceptions or supplier follow-ups, starting on events and remembering context across shifts.

See what's new →  Microsoft Copilot Blog
Power Platform (Dataverse)
Build governed apps on your business data from a prompt

What's new: The Dataverse plugin now works in Copilot Cowork, major coding agents and n8n, sharing the same open-source skills and permission guardrails.

Why it matters: Teams can spin up governed apps on shared business data from a prompt, cutting backlog for plant trackers and quality logs.

Read the post →  Microsoft Power Platform Blog
Security
Put limits on what every agent is allowed to do

What's new: Monthly roundup: task-scoped Dynamic Permissions for agents, generally available Microsoft Execution Containers for local agents, and expanded Intune Endpoint Privilege Management.

Why it matters: As agents touch ERP and plant data, you can cap what each agent may do and keep shop-floor PCs least-privileged.

Read the roundup →  Microsoft Security Blog
AI Workforce / Agents (Microsoft 365 E7)
One control tower for every agent you run

What's new: Gartner's first agent-management Magic Quadrant names Microsoft a Leader for Agent 365, which is included in Microsoft 365 E7 and adds a new Action Center.

Why it matters: One registry and identity for every agent, including third-party ones, helps keep agent sprawl across plants and functions governed and auditable.

Read the post →  Microsoft Security Blog
