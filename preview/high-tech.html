For software builders, the big change this month is that the agent engine behind Microsoft's own Copilots is now available to use in your products and dev tools.

1 big thing

Visual Studio's Copilot gets a new, smarter engine

What's new: From Visual Studio 2026 version 18.12, Copilot Chat runs on the GitHub-built Copilot SDK and is on by default. Developers can steer it mid-task, watch subagents work and see what each request costs.

Why it matters for tech: Engineering teams get more coding tasks done with the same models. Agent skills also work the same way across Visual Studio, VS Code, the CLI and the GitHub Copilot app.

Story 2

Build agents on the engine behind GitHub Copilot

What's new: The agent harness that runs Microsoft's own Copilot products is now available through Microsoft Foundry. It supports 20+ frontier models and bring-your-own-key, as a downloadable SDK or a managed cloud service.

Why it matters for tech: Software companies can stop building and maintaining their own agent loop and model router. They can swap models freely and focus on the product features that set them apart.
Source: The Official Microsoft Blog · Oct 28

An AI-first services firm practises what it sells

Marlabs replaced its HR help desk with a Copilot Studio agent that handles 80% of queries. Its developers also report working 20% faster with GitHub Copilot.

 
One move for Product · High Tech & Software

Rank a messy pile of feature requests

Feature requests arrive from sales, support and customers in different words. Copilot can merge duplicates and rank them.

Copy this prompt
I've attached 120 feature requests from customers and our sales team. Merge duplicates, group them into themes, and rank the top 10 by how many customers asked and how much revenue they mention. Show it as a table.

Where it works: Works in Copilot Chat: paste or attach your file. Why it works: it gives Copilot a goal, context, details and the data to use.

New in Copilot: Look for three tabs in the Copilot app: Chat for quick questions and drafts, Cowork for longer work you hand off, and Code for building small tools. A Work IQ switch decides whether answers use your work data or only the web.
